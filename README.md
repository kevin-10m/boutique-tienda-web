# boutique-tienda-web
Aplicación web para una tienda de ropa ficticia (proyecto del curso).


Aplicación web para Boutique, una tienda de ropa femenina ficticia creada como caso de estudio del curso. El proyecto modela una tienda en línea donde las clientas pueden ver el catálogo, comprar prendas y dar seguimiento a sus pedidos, y donde el administrador gestiona productos, pedidos, cupones y reportes.

Problema

Las tiendas pequeñas de ropa suelen vender por mensajes en redes sociales, lo que hace lentas las consultas de tallas, la disponibilidad y los pagos. Esta aplicación ofrece un canal propio para mostrar los productos y recibir pedidos de forma ordenada.

Usuarios
Usuario visitante: ve el inicio, el catálogo y las ofertas sin iniciar sesión.
Clienta: se registra, compra, paga con tarjeta o SINPE Móvil y sigue sus pedidos.
Administrador: gestiona productos, inventario, pedidos, cupones y reportes de ventas.
Funcionalidades principales
Registro, inicio de sesión y recuperación de contraseña
Catálogo con filtros, búsqueda, ofertas y guía de tallas
Carrito de compras con cupones de descuento
Pago con tarjeta (simulado) o SINPE Móvil
Mi cuenta: historial y seguimiento de pedidos, lista de deseos y perfil
Panel de administrador: productos, pedidos, cupones y reportes
